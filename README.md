

<h1>GitHub Unfollower Viewer Script | Github Unfollow Checker</h1>

<h2>Description</h2>
<p>This is a browser script that adds a "Scan Unfollowers" button to user profile pages on GitHub. When clicked, it
    scans the user's followers and following lists and displays a list of users who do not follow them back in a clean,
    easy-to-read modal window.</p>

<h2>How to Use</h2>
<ol>
    <li>
        <strong>Navigate to GitHub:</strong> Go to any user's profile page on GitHub (e.g., <code>https://github.com/USERNAME</code>).
    </li>
    <li>
        <strong>Open Developer Console:</strong> Open your browser's developer console. You can usually do this by
        pressing <code>F12</code>, or right-clicking on the page and selecting "Inspect," then choosing the "Console"
        tab.
    </li>
    <li>
        <strong>Run the Script:</strong> Copy the code from the box below and paste it directly into the developer
        console, then press <code>Enter</code>.
    </li>
    <li>
        <strong>Scan for Unfollowers:</strong> A "Scan Unfollowers" button will appear on the profile page. Click it to
        start the scan and see the results.
    </li>
</ol>
